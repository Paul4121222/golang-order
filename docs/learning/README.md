# 學習筆記

這個資料夾放的不是「改了什麼」的變更紀錄，而是**當初為什麼這樣寫、當初怎麼判斷的**。
目的是未來重讀時能重建整條推理過程，而不只是看到結論。

每篇筆記的固定結構：

1. **當初的問題** — 我卡在哪、我原本以為是什麼
2. **結論** — 一句話的答案
3. **知識點** — 這次真正學到的機制（可以脫離本專案獨立使用的知識）
4. **推理過程** — 怎麼從觀測資料反推出結論（最有價值的部分）
5. **實驗紀錄** — 原始輸出，以及驗算
6. **未追完的線索** — 下次可以往哪挖
